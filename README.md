# PipeNotcher

PipeNotcher は、丸パイプ同士を任意の角度で接合するための「相貫線型紙」を実寸PDFで生成するWebアプリです。

## 目的

DIY、配管、バイクフレーム製作、ロールケージ製作、金属加工などで使用できる、実寸印刷対応の相貫線型紙をスマートフォンだけで簡単に作成できることを目的とします。

---

## 主な機能

- 同径・異径パイプ対応
- 主管より枝管が大きい組み合わせにも対応
- 実寸A4 PDF生成
- 自動ページ分割
- センターライン表示
- 切断線表示
- 貼り合わせ用十字マーク
- ページ番号表示
- タイトル表示
- 100mm実寸確認スケール表示

---

## 対応パイプ径（Ver1.0）

- φ27.2
- φ34.0
- φ48.6
- φ60.5
- φ76.3
- φ89.1

## 対応角度（Ver1.0）

- 45°
- 90°

※内部計算エンジンは任意角度へ拡張可能な設計とする。

- 実寸印刷対応（100%印刷）
- 必要に応じて複数ページへ自動分割

## 開発方針

本ソフトは見た目よりも計算精度を優先する。

相貫線は近似式ではなく、円柱同士の幾何学的な相貫線を計算して生成する。

将来的な機能追加を考慮し、拡張しやすい構造で実装する。
